# V0.6 contextual comparisons and stop windows

Local report/core: `0.6.0` / `passive-core-0.6.0`; policy: `passive-policy-1.2`. Evidence/conclusion protocols remain `1.2` with additive derived fields. Reports bind algorithm version; old results are not new analyses. Legacy readers remain supported. No parameter recommendation, CLI command or write path is introduced.

## Stop windows

`command_change` marks the initial detected change. Confirmed `command_stop` includes continued return input through the stable near-zero platform start. `post_stop` starts at that platform's first sample, not after its 50ms confirmation. `stopTiming` records initial change end, platform start and continued-input duration. Labels may overlap; never sum durations.

Gyro `residual` remains angular-rate activity. `trackingErrorResidual` measures Gyro minus Setpoint, with separate peaks, segmented RMS and tail/initial ratio. Post-stop `command` carries target mean, RMS and peak. A nonzero target is not tracking error. Neither alternating peaks nor a tail ratio establishes PID damping, attitude rebound or resonance.

`stopResponses` summarizes nonoverlapping observations per axis, including a lower-marked-confound subset. Quantiles require five finite measurements. Truncation, insufficient observation and initially small activity remain distinct; missing decay is not zero. Full per-group statistics remain local; AI gets per-axis distributions and every original action-group summary.

## Context and motor association

`parameterAttribution.status=not_supported` lists context blockers and lack of parameter causality. Context selection never discards events for poor Gyro response. Low marked confounds is not verified flight: actual armed/airborne intervals remain unknown.

Command-room P5/P50 uses 256-bin left-endpoint time-weighted histograms (resolution 1/256). Union room is the minimum across motors. Boundary-run P50/P95 counts each run once; invalid data and span boundaries terminate union runs. Per-motor denominators are independent.

`boundaryAssociation` uses common valid left-endpoint time and an explicit uncalibrated engineering threshold of 30 degrees/s for absolute tracking error. Joint duration, fractions and error RMS near/away from command bounds describe association, not PID causality or physical thrust/torque limits. Empty conditional denominators remain null.

For verified firmware `2026.6.2 (e0b7bb01b)`, DISARM records a real armed-to-disarmed transition. `armingEvidence` exposes bounded event metadata and neighboring-frame time bounds. No independent event timestamp exists; absent upper bounds remain null. Do not backfill armed intervals across gaps or rearming, or infer airborne state.

## AI budget

Protect an available low-context qualified tracking event and lower-command constraint event per axis. Typical tracking uses the middle event in chronological order, not the best response. Stop selection prefers lower marked confounds when available; absence stays explicit.

Keep every tracking/action-group summary and the coverage ledger under 96KiB. Trim optional spectral points, estimates, channel/phase details and unprotected representatives with explicit counters. Balanced events are protected. If required content exceeds the limit, fail explicitly; full local results remain usable. Compaction must not mutate local evidence.
