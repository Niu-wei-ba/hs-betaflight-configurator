## 集成处理

- 保留快照模式的 MSP / CLI 写入限制与缺失响应处理；Setup 和 Power 同时识别请求取消与快照缺失。
- Sensors 采用上游统一修改状态工具，保存前固定快照、持久化成功后更新基线。保留本地用户主动定位、手动坐标、GPS 后备和缓存参考信息显示；不恢复上游已被本地替代的自动 IP 磁偏角应用流程。
- 保留测距 API 1.46 支持、版本化资源路径、品牌、教程、PWA 缓存隔离；正式版与 Dev 的电调音乐等既有功能边界不变。
- HTML 保留 UTF-8 与旧浏览器兼容提示，使用显式 `app` 闭合标签并加入移动安全区域适配。
- 遥控器模拟器继续使用本地 `runtimeAssetUrl`；移除构建中会覆盖编译结果的原始组件复制，次级入口不再注入错误的 PWA manifest。
- 补齐简体中文的加速度计校准页面指引，并移除已废弃的更新网站文案键。
- 修正上游模拟器翻译交接：ReceiverTab 把翻译对象交给子窗口，子窗口优先读取自己的对象，保留父窗口与键名后备。
- 上游 Autotune 提交中的开发者本机 `node_modules` 软链接及后续删除不纳入本地提交，只移植代码和测试。
