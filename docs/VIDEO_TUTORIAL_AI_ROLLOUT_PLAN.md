# 视频教程与 AI 辅助：分阶段上线计划

> 本文是 Betaflight Configurator 视频教程功能的发布边界与后续 AI 方案说明。它不包含任何密钥、服务器地址、内部路径、数据库配置或运维凭据。

## 1. 目标

为用户提供可浏览的 Betaflight 教程视频，并在后续以**教程内容检索、章节定位和步骤关联**的方式增强使用体验。

核心原则：

- 第一阶段先稳定上线教程视频中心，不依赖 AI 服务。
- 第二阶段的视频下载与媒体解析只在管理员本地电脑执行；生产服务器不接收、不保存原始媒体。
- 使用阿里云百炼完成内容解析；服务器只保存结构化文本和检索索引。
- 暂不提供面向公网的生成式 AI 问答或通用聊天能力。
- 开源仓库只保存可公开的实现与示例，绝不提交任何生产环境信息或凭据。

---

## 2. 阶段概览

| 阶段 | 范围 | 是否依赖 AI / 服务端 | 发布目标 |
| --- | --- | --- | --- |
| 阶段一：教程视频中心 | 教程列表、分类、文案、本地/外部视频播放体验 | 否 | 尽快作为独立功能上线 |
| 阶段二：AI 辅助教程索引 | 本地解析任务、百炼解析、文本入库、教程搜索与时间点定位 | 是，但不开放生成式回答 | 在阶段一稳定后单独开发、验收、上线 |

### 2.1 阶段一状态与边界

阶段一在分支 `codex/tutorial-videos-phase-1` 开发，基线提交为：

```text
f93e12d3 feat: add video tutorial center
```

阶段一只包含教程视频中心。**不包含**以下内容：

- 百炼调用或任何 AI Key；
- 视频下载、转码、字幕解析任务；
- 生产服务器 API、数据库、队列或 Worker；
- 公网 AI 搜索、生成式回答或后台管理入口。

阶段一应独立发布，不等待第二阶段。

### 2.2 阶段二状态与边界

阶段二使用独立分支 `codex/tutorial-ai-phase-2`，以阶段一提交为基线开发。

阶段二的目标是让系统能基于已入库教程提供：

- 关键词搜索；
- 相关教程推荐；
- 视频章节、步骤、字幕片段与时间点定位；
- 与 Betaflight 配置项相关的教程内容关联。

阶段二不是开放式 AI 聊天产品。检索范围必须限制为已审核的教程内容库；超出内容库的问题不作生成式回答。

## 3. 阶段二总体架构

```text
管理员私有 CLI / 本地自动化服务
  │
  ├─ 1. 接收管理员提供的视频 URL
  ├─ 2. 在本地下载原视频
  ├─ 3. 本地抽取音频和少量关键帧
  ├─ 4. 直接调用阿里云百炼 API 进行解析
  ├─ 5. 生成字幕、时间轴、OCR、步骤摘要和标签
  ├─ 6. 删除本地原视频、音频、关键帧和临时文件
  └─ 7. 向私有入库接口提交结构化文本结果
                         │
                         ▼
                  生产服务器（仅文本）
                  - 教程元数据与审核状态
                  - 字幕 / 转写文本
                  - 时间轴、OCR、步骤摘要、标签
                  - 检索索引 / 向量索引
                         │
                         ▼
              api.bf.hs-fpv.com（受控只读接口）
                  - 教程搜索
                  - 章节与时间点定位
                  - 不提供生成式回答
```

### 3.1 本地解析职责

视频下载任务属于管理员本地电脑，不在生产服务器执行。私有 CLI / 本地自动化服务负责：

1. 校验视频来源、授权状态、时长和文件大小；
2. 下载原视频到受控临时目录；
3. 按需要提取音频与少量关键帧，优先避免上传完整视频；
4. 调用百炼得到可审计的结构化结果；
5. 对结果做格式、时间轴和内容质量校验；
6. 将合格文本结果提交至服务端；
7. 无论成功或失败，均在清理流程中删除媒体及临时文件，并记录不含敏感媒体路径的任务摘要。

本地工具必须使用私有配置文件或环境变量加载百炼凭据；凭据文件不可提交到 Git，不可写入日志。

### 3.2 生产服务器职责

生产服务器只承担文本数据的存储、审核、索引和受控查询：

- 保存教程元数据、文本解析产物及其版本；
- 构建关键词和（如需要）向量检索索引；
- 仅向前端提供已发布教程的只读检索和时间点定位；
- 提供仅供管理员 CLI 使用的私有结果入库通道；
- 不下载、不转码、不解析原视频，不保存原视频、完整音频、关键帧或任务媒体文件。

服务器的独立数据盘仅可用于文本索引、数据库备份和受控运行数据；不得作为视频存储盘或临时媒体缓存。

## 4. 数据保留与删除规则

| 数据类型 | 产生位置 | 保留位置 | 保留规则 |
| --- | --- | --- | --- |
| 原始视频 | 管理员本地 | 不保留 | 百炼请求及结果入库完成后立即删除；失败路径也必须清理 |
| 派生音频 | 管理员本地 | 不保留 | 任务完成或失败后立即删除 |
| 关键帧图片 | 管理员本地 | 不保留 | 任务完成或失败后立即删除 |
| 字幕 / 转写文本 | 本地生成后提交 | 生产服务器 | 按教程内容版本保留，支持纠错和重新解析 |
| OCR、时间轴、步骤摘要、标签 | 本地生成后提交 | 生产服务器 | 作为检索和展示数据保留 |
| 检索 / 向量索引 | 生产服务器 | 生产服务器 | 可由上述文本重建，不作为唯一数据源 |
| 任务日志 | 本地及服务端 | 最小化保留 | 仅保留任务 ID、状态、耗时、错误码等，不记录密钥、媒体内容、临时文件路径或完整请求体 |

删除流程必须可重试，并在任务异常退出后由清理器兜底处理遗留临时文件。

## 5. API、访问控制与安全边界

### 5.1 公网接口：`api.bf.hs-fpv.com`

公网只读接口遵循最小能力原则：

- 仅返回已经审核并发布的教程数据；
- 初期仅支持教程搜索、分类筛选、章节和时间点定位；
- 不返回内部任务状态、原始解析请求、百炼响应、后台日志或运维信息；
- 不提供通用聊天、自由提示词输入或生成式回答接口；
- 实施速率限制、参数校验、分页上限、缓存和审计告警，防止批量爬取和资源滥用。

### 5.2 私有入库通道

管理员 CLI 提交解析结果的入口必须与公网只读接口隔离：

- 不提供浏览器后台管理页，不暴露任务创建、媒体上传或 Worker 控制接口；
- 使用私有网络访问、访问来源白名单或等效的安全通道；
- 使用短期凭据、双向认证或签名请求，并配合时间戳、随机数和重放保护；
- 服务端对提交方身份、请求体大小、教程 ID、字段结构和版本做严格校验；
- 权限按“仅能提交指定解析结果”拆分，禁止使用全能生产凭据。

### 5.3 密钥与开源边界

以下内容不得进入开源仓库、前端构建产物、示例请求或公开日志：

- 百炼 API Key、AccessKey、临时令牌；
- 数据库、缓存、对象存储、消息队列及第三方服务凭据；
- 私有 API 地址、服务器 IP、SSH 用户、端口、内部目录、Docker 卷名；
- 防火墙规则、监控告警 Webhook、任务日志和生产数据样本；
- 可绕过访问控制的测试账号、固定签名密钥或管理接口文档细节。

公开代码只能提供 `.env.example` 中的空变量名、脱敏配置说明和本地开发 mock。

## 6. 服务端部署原则

第二阶段服务部署在独立的生产服务环境中，并遵循：

- 独立 Docker Compose 项目、独立 Docker 网络和独立数据卷；
- 容器不直接映射管理端口到公网；对外访问仅经受控反向代理；
- 数据库、索引服务、队列和 Worker 仅加入内部网络；
- 为各容器设置 CPU、内存、磁盘空间、日志滚动和重启策略，防止影响已有业务；
- 在上线前完成备份、回滚方案、健康检查和既有服务回归验证；
- 主机加固采用分阶段方案：先隔离新服务，再在维护窗口完成 SSH/root 策略、主机防火墙和既有面板来源等存量风险的整改。

视频计算不落在服务器，能显著降低 CPU、内存、磁盘 I/O 与带宽压力；服务器负载主要来自文本索引和受控查询。仍需对索引构建、批量入库和异常请求设置并发及资源上限。

## 7. 阶段二实施清单

### 7.1 本地私有工具

- [ ] 定义管理员 CLI 的任务参数、权限和失败退出码。
- [ ] 实现视频下载、来源/大小/时长校验与临时目录隔离。
- [ ] 实现音频提取、关键帧抽取及媒体清理器。
- [ ] 封装百炼 Provider，支持超时、重试、限流、错误分类和脱敏日志。
- [ ] 规范化输出：字幕、时间轴、OCR、步骤摘要、标签和解析版本。
- [ ] 在提交前执行结构校验和人工审核标记。

### 7.2 服务端私有入库与存储

- [ ] 设计教程、解析版本、文本片段、时间轴、标签与审核状态的数据模型。
- [ ] 实现私有入库 API、身份认证、重放保护、幂等键和审计记录。
- [ ] 实现文本检索索引；向量检索仅在有明确需求时启用。
- [ ] 提供重新解析、回滚、下线和删除文本索引的管理能力，但仅限私有运维通道。
- [ ] 编写备份、恢复和索引重建 SOP。

### 7.3 受控只读查询

- [ ] 设计公开教程搜索、分类筛选、章节列表、时间点定位 API。
- [ ] 仅展示已发布和已审核的内容版本。
- [ ] 实施限流、缓存、参数白名单、响应字段最小化和安全监控。
- [ ] 明确不实现公网生成式回答、通用问答或任意 URL 解析。

### 7.4 发布与验收

- [ ] 阶段一先独立发布并验证教程中心功能。
- [ ] 阶段二在隔离分支完成开发、测试和安全评审后再合并。
- [ ] 使用非生产样本验证“成功、百炼失败、入库失败、进程中断”四类场景均能清理媒体。
- [ ] 进行权限绕过、重放请求、超大请求、批量爬取和敏感日志检查。
- [ ] 上线后验证既有生产服务性能、健康检查、备份和回滚路径。

---

## 8. 明确不做的事项

在第二阶段验收前，以下事项不在范围内：

- 在生产服务器下载、存储或解析教程原视频；
- 让用户上传视频或提交任意外部视频 URL 进行解析；
- 向公网暴露 Worker、队列、数据库、管理后台或任务日志；
- 将完整视频、音频或大量图片作为常规解析输入长期传输或保存；
- 开放生成式教程回答、开放域问答或通用 AI 聊天。

任何扩展到生成式回答、用户投稿视频或媒体持久化的需求，都必须重新进行单独的产品、成本、版权、隐私和安全评审。
