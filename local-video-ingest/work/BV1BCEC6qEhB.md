# 第五集：Betaflight地面站失控保护界面设置

## 本教程讲什么

本教程讲解 Betaflight Configurator 的**失控保护（Failsafe）**页面：如何理解有效脉冲范围、第一阶段通道回退、进入第二阶段的方式，以及坠落、自动降落和 GPS 救援等应急行为。视频重点是减少遥控信号丢失时的飞行风险。

## 适用场景与前置条件

- 已安装并能打开 Betaflight Configurator。
- 已能正常连接飞控。
- 计划为穿越机配置遥控信号丢失后的保护行为。
- 如需使用 GPS 救援，视频要求在失控保护页面开启 GPS 救援选项；其余 GPS 条件和具体参数，视频未明确说明。

## 操作步骤

### 1. 打开失控保护页面

连接飞控后，进入 Betaflight Configurator 的“失控保护”页面。该页面用于设定遥控信号无效或失联时，飞控应如何处理飞机。

### 2. 检查有效脉冲范围

查看有效脉冲范围的最小值和最大值。通道值低于最小值或高于最大值时，飞控会判定信号异常并触发失控保护。视频建议绝大多数场景保持软件默认值，避免因随意修改阈值导致误触发。

### 3. 选择第一阶段的通道回退方式

视频将回退方式分为三类：

- **AUTO**：滚转、俯仰和偏航回中，油门降到最低。视频将其作为日常飞行中较安全、适合新手的选择。
- **HOLD**：保持信号中断前最后一个有效通道值。视频提示该方式会让飞机保持失联前姿态，风险较高。
- **SET**：为通道手动设置固定值，适合进阶调试。

视频说明，回退值以 25 微秒为步进保存，细微的小数调整不会生效。

### 4. 选择进入第二阶段的方式

视频介绍了第一阶段、第二阶段和终止模式：

- **第一阶段**：先经过约 1.5 秒的缓冲，再进入第二阶段。视频将其作为日常调试和正常飞行的首选。
- **第二阶段**：跳过第一阶段，直接进入第二阶段应急程序。视频认为它更适合专项测试。
- **终止模式**：失联时直接解锁并停机，可能造成坠落；视频明确提示风险很高。

第二阶段保护时间的具体值，视频未明确说明；视频只说明它用于设定信号丢失后经过多久触发第二阶段。

### 5. 按飞行条件选择应急行为

视频列出第二阶段的三类应急行为：

- **坠落**：直接解锁停机。视频将其用于没有 GPS 的穿越机。
- **自动降落**：飞控控制油门和姿态，让飞机缓慢下降。视频将其用于有一定高度、希望尽量保机的场景。
- **GPS 救援**：信号丢失时触发 GPS 救援返航。视频说明信号恢复后可大幅度拨动任意摇杆取消返航，再手动接管。

视频提到自动降落相关的油门设置和电机关闭延时可保持默认值，但没有明确给出具体数值。

| --- | --- |
| 有效脉冲范围 | 用于判定遥控信号是否有效；多数场景建议保留软件默认值。 |
| 通道回退 | 包含 AUTO、HOLD、SET；视频建议新手优先使用 AUTO。 |
| 第二阶段保护时间 | 决定信号丢失后多久触发第二阶段；具体参数值视频未明确说明。 |

| GPS 救援 | 需在失控保护页面开启；其他配置参数视频未明确说明。 |

## 常见错误与注意事项

- 不要随意改动有效脉冲范围，避免误触发失控保护。
- HOLD 会保持失联前的通道值，视频不建议新手使用。
- 终止模式会直接停机，风险很高，不适合日常飞行。
- GPS 救援不是消费级航拍机的自动返航替代品，不应完全依赖。
- 起飞前选择开阔位置，避开高楼、树木和电线等遮挡。
- 设备通电后保持静止，等待 GPS 搜星充足再起飞。
- 遥控信号和图传画面恢复后，视频建议尽快手动接管并自主返航降落。

## 视频章节

### 1. 进入失控保护页面

目标：找到失控保护设置入口。

操作：连接飞控并进入“失控保护”页面。

注意：本视频没有可靠时间轴，不能据此推断具体时间点。

### 2. 检查有效脉冲范围

目标：理解飞控如何识别异常遥控信号。

操作：查看最小值和最大值，并按视频建议在多数场景保持默认值。

注意：随意修改可能造成误触发。

### 3. 设置第一阶段通道回退

目标：选择信号无效时的通道行为。

操作：理解 AUTO、HOLD 和 SET 的差异；新手可按视频建议优先使用 AUTO。

注意：HOLD 的飞行风险较高。

### 4. 选择失控保护阶段与应急行为

目标：确定第二阶段的触发方式和保护行为。

操作：了解第一阶段、第二阶段、终止模式，以及坠落、自动降落和 GPS 救援。

注意：视频不建议日常飞行直接使用第二阶段或终止模式。

### 5. 启用 GPS 救援并做好起飞前准备

目标：把 GPS 救援作为失联时的应急兜底。

操作：开启 GPS 救援选项，选择开阔起飞点并等待 GPS 搜星充足。

注意：不要高度依赖 GPS 救援。
