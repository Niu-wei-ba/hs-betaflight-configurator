# 第二集：Betaflight地面站端口设置界面

## 本教程讲什么

本教程讲解 Betaflight 地面站“端口”页面的基础配置：如何让飞控 UART 与接收机、GPS、图传等外设的接线对应，并避免因串口功能冲突导致配置失效。

## 适用场景与前置条件

- 已能连接 Betaflight 地面站。
- 已确认外设接在飞控的哪一组 RX/TX 焊盘。
- 修改端口前建议记录当前配置；USB 配置端口不要随意关闭。

## 操作步骤

### 1. 确认外设接在哪个 UART

端口页面中的 UART1、UART2、UART3 等条目对应飞控板上的 RX/TX 焊盘。接收机、GPS 或图传控制线接在哪一组焊盘，就配置同编号的 UART。

### 2. 配置数字接收机

在数字接收机接入的 UART 行开启“串行接收机”。视频说明，ELRS 等双向数字接收机通常与遥测共用同一串口，无需额外开启遥测输出。

### 3. 配置 GPS 或其他传感器

GPS、部分电调遥测等设备使用的 UART，需要开启传感器输入，并按设备实际要求匹配波特率。视频未明确说明所有设备的通用波特率。

### 4. 按图传类型配置控制协议

数字图传按视频说明启用 **VTX MSP** 和 **DisplayPort**。模拟图传则按所使用的 VTX 控制协议选择对应选项；不同设备的协议不同，不能照搬不匹配的设置。

### 5. 保存并检查冲突

关闭未使用的端口功能后保存。重新连接地面站检查配置是否仍在；如果保存后端口设置全部归零，应检查是否有串口功能冲突。

## Betaflight 参数与界面说明

- **UART**：飞控与外设通信所用的串口，对应板上的 RX/TX 焊盘。
- **MSP**：飞控与需要直接通信的外设之间使用的通信协议。视频建议没有明确需求时不要额外开启。
- **串行接收机**：数字接收机所在 UART 需要启用的功能。
- **传感器输入**：用于 GPS、部分电调遥测等传感器类外设。
- **遥测输出**：视频说明，新式双向数字接收机通常不需要单独开启。
- **VTX MSP / DisplayPort**：视频用于数字图传控制与 OSD 显示的配置项。

## 常见错误与注意事项

- 接线 UART 与页面中启用功能的 UART 不一致，外设不会正常工作。
- 关闭 USB 对应端口可能导致无法再通过 USB 连接地面站。
- 不要在同一个 UART 开启彼此不兼容的功能；冲突时飞控可能重置所有端口配置。
- 不要为了“以后可能会用”而开启多余功能，只开启当前接入设备所需项目。
- GPS 的波特率和协议应以实际设备要求为准，视频未明确说明通用默认值。

## 术语表

| 术语 | 含义 |
| --- | --- |
| UART | 飞控与外设进行串行通信的端口。 |
| MSP | Betaflight 与外设之间常用的通信协议。 |
| 串行接收机 | 在接收机接入的 UART 上启用的接收机接口功能。 |
| DisplayPort | 视频中用于数字图传 OSD 显示的相关配置项。 |
