# 穿越机刷固件必看：飞控识别不到、连不上地面站？一招搞定驱动与BOOT键问题

## 本教程讲什么

本教程处理刷写固件时“飞控无法被电脑或 Betaflight 地面站识别”的常见情况。视频演示了在 Windows 设备管理器中查找飞控设备、回退或更新驱动，以及按住 BOOT 键再插入 USB 的进入刷写模式方法。

## 适用场景与前置条件

- 适用于飞控已通过 USB 接入电脑，但 Betaflight 地面站无法正常连接或刷写时。
- 需要使用 Windows 设备管理器检查驱动状态。
- 操作前断开动力电池；如需接触电机相关设置，应先拆下桨叶。
- 飞控型号、Windows 版本和具体驱动版本，视频未明确说明。

## 操作步骤

### 1. 在设备管理器中找到飞控设备

1. 在 Windows 中右键“此电脑”，选择“管理”，打开设备管理器。
2. 先在“通用串行总线设备”中寻找与 Betaflight 或 STM32 相关的设备。
3. 如果没有找到，再打开“端口（COM 和 LPT）”，查找以 STM 开头的端口。

### 2. 回退或更新驱动程序

1. 右键目标设备并打开“属性”。
2. 进入“驱动程序”页，按视频顺序先尝试“回退驱动程序”。
3. 回退无效时，选择“更新驱动程序”。
4. 完成后重新打开 Betaflight 地面站，确认是否能正常连接。

### 3. 用 BOOT 键进入刷写状态

1. 按住飞控上的 BOOT 键。
2. 保持按住后插入 USB。
3. 再继续进行驱动安装或固件刷写。

视频指出，未按住 BOOT 键就直接插线刷写，可能导致电脑或地面站无法识别飞控。

- **BOOT 键**：用于让飞控进入视频所述的刷写状态；具体位置请以飞控板丝印和厂商说明为准。
- 具体驱动名称、固件目标和刷写选项，视频未明确说明。

## 常见错误与注意事项

- 不要把飞控的驱动问题与其他 USB 设备混淆；只对确认的目标设备操作。
- 更新或回退驱动后应重新连接并重新打开地面站验证。
- BOOT 键操作顺序是先按住，再插入 USB。
- 视频没有给出针对所有飞控型号的通用驱动版本；若问题仍在，请以飞控厂商资料为准。

## 视频章节

### 1. 确认连接异常和设备位置

- 目标：在 Windows 设备管理器中找到飞控对应设备或端口。
- 操作步骤：打开“计算机管理”中的设备管理器。；在“通用串行总线设备”或“端口（COM 和 LPT）”中查找 Betaflight / STM32 相关设备。
- 注意事项：设备名称会随飞控型号和驱动状态变化，视频未提供统一名称。

### 2. 回退或更新驱动

- 目标：让系统重新使用可用的 USB / 串口驱动。
- 操作步骤：右键目标设备，打开“属性”。；在“驱动程序”页按视频顺序尝试“回退驱动程序”；无效时再选择“更新驱动程序”。；完成后重新打开 Betaflight 地面站测试连接。
- 注意事项：不要随机卸载其他 USB 设备的驱动。

### 3. 使用 BOOT 键进入刷写状态

- 目标：按视频顺序让飞控进入刷写所需状态。
- 操作步骤：按住飞控上的 BOOT 键。；保持按住的同时插入 USB。；再继续后续驱动或固件刷写操作。
- 注意事项：实际 BOOT 键位置因飞控而异；操作电机相关项目时应先拆桨。
