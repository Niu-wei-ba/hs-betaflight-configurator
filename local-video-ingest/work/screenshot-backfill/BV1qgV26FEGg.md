# 七寸远航悬停教程，四个步骤告别飘移乱晃

## 本教程讲什么

本教程以七寸远航机为例，介绍定点、定高悬停的四个实操环节：备份飞控配置、刷写带位置保持与高度保持功能的固件、在地面站恢复配置并完成相关设置，以及在室外确认 GPS 条件后测试悬停。

## 适用场景与前置条件

- 适用于计划在 Betaflight 飞控上尝试位置保持和高度保持的用户。
- 需要飞控、GPS 及视频所涉及的相关功能已经安装并能被地面站识别。
- 操作前应断开动力电池、拆桨，并备份原配置。
- 飞控目标、固件版本、GPS 型号、罗盘使用方式和实际兼容性，视频未作通用确认。

## 操作步骤

### 1. 备份原有飞控配置

1. 连接飞控，进入 CLI。
2. 输入 `dump` 并回车。
3. 将输出保存为文件，以便刷写后恢复。

### 2. 让飞控进入刷写状态并选择固件

1. 按住飞控上的 BOOT 键，再插入 USB。
2. 在驱动工具中确认选择的是带 **STM32 Bootloader** 标识的设备。
3. 打开 Betaflight 固件刷写工具，选择正确的飞控目标。
4. 按实际接收机选择 CRSF 或 SBUS，按实际图传选择数字或模拟 OSD。
5. 根据视频所示功能选择高度保持、位置保持、电子罗盘、LED 和舵机等实际需要的项目。
6. 从网络加载固件后开始刷写。

### 3. 恢复配置并完成地面站设置

1. 刷写完成后进入 CLI，从文件加载第一步的备份并执行。
2. 输入 `save` 保存恢复后的配置。
3. 视频将位置保持和高度保持的相关参数先设为较低值；如果飞行中位置漂移或高度起伏，再按视频的方向逐步提高。
4. 视频还展示了在不使用磁力计的场景中启用位置保持相关选项的思路；该项必须按实际 GPS、罗盘和当前固件提示确认。
5. 在“模式”页面把高度保持和位置保持分配到同一个遥控器通道，使其同时启用或关闭。

### 4. 在室外测试悬停

1. 起飞前确认 GPS 卫星数量充足；视频建议至少八颗。
2. 先让飞机匀速直线飞行一段距离，并进行较大俯仰动作。
3. 再开启位置保持和高度保持，观察是否能够稳定悬停。
4. 若无法开启，先回到定位条件与飞行动作检查，不要强行依赖自动悬停。

## Betaflight 参数与界面说明

- **位置保持**：视频用于实现自动定点。
- **高度保持**：视频用于实现自动定高。
- **位置保持 + 高度保持**：视频将两者同时开启，作为定点定高悬停方案。
- **CRSF / SBUS**：应按实际接收机、图传与飞控连接方式选择。
- **CLI 的 `dump` / `save`**：分别用于导出配置和保存配置。
- 具体 CLI 参数名称、允许范围和固件版本，视频未明确给出可通用复用的完整清单。

## 常见错误与注意事项

- 恢复旧配置前先确认它与新固件兼容；报错时不要跳过检查。
- 进入刷写模式时应确认设备名称包含 Bootloader。
- 高度保持和位置保持依赖实际传感器与定位条件，不能只靠开关配置就保证可用。
- 视频建议在卫星数充足并完成必要飞行动作后再开启悬停；首次测试应在开阔、可控的环境进行。

## 术语表

- **位置保持**：视频中用于自动定点的功能。
- **高度保持**：视频中用于自动定高的功能。
- **GPS**：用于获取卫星定位信息的模块。
- **BOOT 键**：让飞控进入视频所述刷写状态的按键。
- **STM32 Bootloader**：视频中用于确认刷写状态的设备标识。
- **Zadig**：视频中用于安装 STM32 Bootloader 驱动的工具。

## 视频章节

### 1. 备份飞控配置

- 目标：在升级前保存当前配置，以便刷写后恢复。
- 操作步骤：连接飞控并进入 CLI。；执行 `dump`。；把输出保存为文件。
- 注意事项：恢复旧配置前应确认其与新固件兼容。

### 2. 进入刷写模式并安装驱动

- 目标：让飞控以 STM32 Bootloader 状态被电脑识别。
- 操作步骤：按住 BOOT 键后插入 USB。；打开 Zadig，在设备列表中选择带有 STM32 Bootloader 标识的设备。；安装驱动后进入 Betaflight 的固件刷写页面。
- 注意事项：只有显示 Bootloader 时才是视频所说的刷写状态。

### 3. 选择固件功能

- 目标：为悬停方案选择接收机、OSD 和所需功能。
- 操作步骤：选择与飞控匹配的目标和视频所示固件版本。；按实际接收机选择 CRSF 或 SBUS。；按实际图传选择数字或模拟 OSD，并勾选高度保持、位置保持等实际需要的功能。
- 注意事项：视频提到的功能列表和版本是示例，不应直接套用到所有飞控。

### 4. 恢复配置并设置悬停参数

- 目标：恢复原配置后设置位置保持与高度保持相关参数。
- 操作步骤：在 CLI 中加载备份文件并执行 `save`。；按视频给出的思路设置位置保持和高度保持的相关参数。；把高度保持与位置保持放在同一遥控器通道，同时启用或关闭。
- 注意事项：文中的具体参数范围和命令应以视频、当前固件提示和实际硬件为准。

### 5. 室外测试

- 目标：在安全的卫星接收条件下验证悬停。
- 操作步骤：确认 GPS 卫星数量充足，视频建议至少八颗。；先匀速直线飞行一段距离并做较大俯仰动作。；再尝试开启位置保持和高度保持。
- 注意事项：不要在没有确认定位条件时依赖悬停功能。
