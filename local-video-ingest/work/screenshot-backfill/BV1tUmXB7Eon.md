# 【科普教程】怎么刷写BF4.6？怎么设置悬停？时钟同步有必要吗？

## 本教程讲什么

本教程讲解如何刷写视频所称的 Betaflight 4.6 系列固件、选择高度保持与位置保持相关功能，并在地面站中配置定点定高悬停。视频还说明了原有地面站可能不支持新固件、需要改用在线地面站的情况，以及时钟同步与自动悬停并非同一前提。

## 适用场景与前置条件

- 适用于准备升级 Betaflight 固件、尝试高度保持和位置保持的用户。
- 需要先确认飞控目标、接收机协议、图传类型，以及 GPS 等实际硬件条件。
- 刷写前断开动力电池并拆桨；保存原配置。
- 视频中的版本命名和在线地面站兼容性可能随发布变化，必须以当前官方页面和实际设备为准。

## 操作步骤

### 1. 记录目标和原固件信息

1. 用原有地面站连接飞控。
2. 记录地面站显示的飞控目标和当前固件版本。
3. 进入“更新固件”页面，启用专家模式。

### 2. 选择正确目标、协议和功能

1. 选择与飞控完全一致的目标，避免误刷。
2. 按实际接收机选择 CRSF 或 SBUS。
3. 选择需要的功能；视频以高度保持和位置保持为例。
4. 加载在线固件后，按视频提示选择备份原文件，再确认刷写。
5. 刷写期间不要拔掉飞控。

### 3. 使用可连接新固件的地面站

1. 刷写完成后先尝试重新连接飞控。
2. 如果原地面站提示不支持新固件，按视频改用在线地面站。
3. 连接后按提示校准加速度计，再继续原有配置流程。

### 4. 配置定高、定点与悬停

1. 在“模式”页面查看是否出现高度保持和位置保持功能。
2. 为这两个功能分别配置遥控器开关范围。
3. 同时开启两项时，视频将其作为定点定高悬停方案。
4. 是否可用仍取决于实际传感器、定位条件和飞控支持情况。

### 5. 不把时钟同步和悬停混为一谈

1. 视频认为时钟同步需要相应飞控硬件支持。
2. 视频同时说明，不支持时钟同步并不等于不能使用自动悬停。
3. 视频未给出官方的完整时钟同步说明，不能据此推断具体支持范围。

## Betaflight 参数与界面说明

- **专家模式**：视频用于显示和选择更多刷写选项。
- **高度保持 / 位置保持**：视频在固件刷写时选择，并在“模式”页面配置开关。
- **在线地面站**：当本地地面站不支持新固件时，视频使用的替代方式。
- **时钟同步**：视频称需要飞控硬件支持，但未给出完整官方说明。
- 具体固件版本、传感器型号、功能默认值和硬件兼容性，视频未明确说明。

## 常见错误与注意事项

- 选择错误的飞控目标是刷写风险最高的环节之一，应先记录再选择。
- 本地地面站不能连接新固件，不代表飞控已经损坏；先检查软件兼容性。
- 高度保持与位置保持不是只刷入功能即可安全使用，仍需确认 GPS、传感器和实际飞行条件。
- 不要因旧飞控没有时钟同步就直接判定无法使用视频所述的悬停功能。

## 术语表

- **CRSF / SBUS**：视频提到的接收机协议选项。
- **高度保持**：视频中用于自动定高的功能。
- **位置保持**：视频中用于自动定点的功能。
- **在线地面站**：通过网页打开、用于连接和配置飞控的地面站。
- **时钟同步**：视频讨论的飞控主控与陀螺仪时钟相关能力。
